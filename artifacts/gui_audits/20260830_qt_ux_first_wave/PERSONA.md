# Persona Lock: 시간 제약이 큰 개인 투자자

- Locked at: 2026-08-30 KST
- Source: direct conversation context and current project goals
- Device: Windows desktop, keyboard and mouse
- Baseline viewport: 1600×900 at a desk, approximately 60 cm viewing distance
- Frequency: daily or near-daily market review

## Goals

- 앱을 열자마자 현재 시장·데이터 상태와 오늘 확인할 항목을 빠르게 파악한다.
- 종목이나 시장을 조사하고, 데이터가 최신이고 신뢰할 수 있는지 확인한다.
- 계좌·순자산을 읽기 전용으로 확인한다.
- 필요하면 검증된 백테스트 결과를 찾아보되 주문은 실행하지 않는다.

## Constraints

- 시간이 부족해 화면을 오래 해석하고 싶지 않다.
- 개발자 용어보다 투자 판단에 직접 연결되는 문장을 원한다.
- 잘못된 데이터와 실제 주문 가능성을 특히 경계한다.
- 주요 작업은 세 번 이내의 명확한 선택으로 시작할 수 있어야 한다.

## Pain triggers

- 비슷한 중요도의 카드와 버튼이 한 화면에서 경쟁한다.
- 데이터가 비어 있거나 오래됐는데 이유와 다음 행동이 보이지 않는다.
- 영문 내부 상태 코드나 개발자 진단이 사용자 문장보다 먼저 보인다.
- 클릭 뒤 처리 중인지, 완료됐는지, 실패했는지 알 수 없다.

## Wins

- 첫 화면에서 오늘 볼 것과 데이터 신뢰 상태가 분리돼 보인다.
- 실패 상태가 원인·영향·안전한 다음 행동으로 설명된다.
- 조사 → 상태 확인 → 결과 검토가 맥락을 잃지 않고 이어진다.
