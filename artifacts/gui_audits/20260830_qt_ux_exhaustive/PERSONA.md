# Persona lock

- Role: 개인 자산과 시장 상태를 매일 확인하는 개인 투자자
- Technical comfort: 일반 사용자; 데이터셋 ID나 내부 오류 코드를 해석하지 않음
- Time pressure: 아침 또는 장중에 3–10분 안에 이상 여부와 다음 행동을 판단해야 함
- Emotional context: 금액과 데이터가 틀릴 가능성에 민감하며, 삭제·주문처럼 보이는 행동을 경계함
- Device: Windows 데스크톱, 물리 디스플레이 최대 2560×1440, 약 60 cm 거리
- Locale/input: 한국어, 마우스와 키보드; 터치/RTL은 현재 제품 계약 밖

First-time-user lens: 모든 화면은 소스코드나 내부 문서 없이도 현재 상태, 데이터 신뢰 범위, 다음 안전 행동을 설명해야 한다.
