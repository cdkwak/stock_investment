# Persona Lock

- **역할:** 개인 자금으로 한국 주식과 미국 ETF를 운용하는 1인 퀀트 투자자
- **목표:** 문서·코드·별도 노트 없이 GUI만 보고 오늘의 관찰 후보, 매수/보유/축소/관망 판단, 포지션 크기, 근거와 반증 조건을 결정한다.
- **작업 맥락:** 장 시작 전 또는 장 마감 후 3–10분 안에 시장→종목→포트폴리오→검증 상태를 확인한다.
- **신뢰 조건:** 모든 결론에는 기준시각, 출처, 데이터 적합성, 불확실성, 포트폴리오 영향이 함께 보여야 한다.
- **안전 조건:** 주문·이체는 필요하지 않다. 오래되거나 불완전한 근거는 숫자를 숨기거나 판단을 명시적으로 차단해야 한다.
- **환경:** 한국어 Windows 데스크톱, 마우스와 키보드, 1600×900 주사용, 1280×720 노트북 최소 조건.
- **취향:** 어두운 바탕과 절제된 주황 강조. 색은 상태와 행동 우선순위를 설명해야 한다.
- **첫 사용 렌즈:** 내부 데이터셋 ID와 개발 계약을 몰라도 다음 행동을 이해할 수 있어야 한다.
