# 홈 페이지 표시 계약

홈(`/`)은 보존된 로컬 데이터만 읽는 요약 화면이다. 공급자 호출이나 계좌
변경을 수행하지 않으며, 확인할 수 없는 값은 숫자로 대체하지 않는다.

## 지표 칸

- 한 칸에는 값, 등락, `MA5 … · MA20 …` 한 줄, 미니그래프만 우선 표시한다.
  MA 값은 기간 수익률이 아니라 현재 값과 이동평균의 이격이며, 금리와
  금리 스프레드는 퍼센트가 아닌 bp를 사용한다.
- 미니그래프는 장중 또는 최근 30일 종가를 사용한다. 마지막 값이 첫 값
  이상이면 빨강(`#c0392b`), 작으면 파랑(`#2b62c0`), 같을 때만 중립색으로
  그리고 끝 점을 표시한다. 그래프에는 `장중 09:00~15:30` 또는 `30일`
  꼬리표 하나만 둔다. 한국 3Y·10Y 국채처럼 `source_label`이 있으면 그
  짧은 출처 꼬리표를 우선한다.
- 출처, 관측 시각, 전체 보조문은 칸과 생략된 보조문의 `title`에 둔다.
  화면의 보조문은 한 줄 말줄임하고 전체 문장은 툴팁으로 확인한다.
- USD/KRW의 Yahoo 24시간 관측에 이전 한국시간 세션이 없으면 BOK 일별
  환율을 우선하고, 없을 때만 FRED 일별 환율을 사용한다. 직전 마감과
  MA5/MA20 비교에는 같은 일별 소스를 사용한다.
- `data-symbol`이 있는 지수·ETF 칸만 차트 전환이 가능하다. 금리·스프레드,
  VIX, USD/KRW 등 차트 경로가 없는 칸은 비활성 표시한다.

## 국면 근거

- 국면 점수는 RSI14, 각 지수의 이동평균 이격 백분위, 변동성으로 계산한다.
  추세는 KOSPI의 60일선 이격과 미국 지수의 200일선 이격을 각자 최근
  2,520세션(보존분이 더 짧으면 보존분) 안에서 백분위화하며 750세션 미만은
  `자료 없음`이다. 변동성은 S&P 500에 VIX, KOSPI에 VKOSPI, NASDAQ-100과
  SOX에 각 지수의 20일 연율화 실현변동성 백분위를 쓴다. 과열·공포/침체
  ±2는 RSI와 추세가 같은 방향인 서로 다른 두 근거일 때만 허용하며,
  변동성 단독은 ±1을 넘지 않는다.
- 근거 라벨의 `순위`는 화면에서 `백분위`로 바꾸고, payload의 `hint`를
  값 뒤에 붙인다. 예: `VKOSPI 250일 백분위 44% · 낮을수록 안정`.
- 값이 `근거 없음`, `표시 불가`, `수집 추가 필요` 중 하나이고
  `evidence == false`이면 해당 행을 숨긴다. 같은 국면 열에는
  `근거 없는 지표 N개 숨김`을 한 번만 표시한다.

## 차트와 반응형 표시

- 일/주/월은 이미 받은 일봉을 브라우저에서 집계한다. 주봉은 ISO 주의
  월요일 기준, 월봉은 달력 월 기준이며 별도 API 호출을 만들지 않는다.
- 홈 차트의 `＋ 지표 추가` 메뉴는 MA5/20/60/120, Bollinger(20,2),
  RSI14, 거래량을 전환한다. RSI14는 `SIIndicators.rsiWilder`로 계산하며
  `RSI14 · 아래`와 `RSI14 · 위(겹침)` 중 하나를 고른다. 위 배치는 숨긴
  0–100 전용 축과 30/70 점선으로 캔들 영역에 겹치므로 가격 축을 바꾸지
  않는다. 선택은 시장값이 아닌 표시 환경설정
  `localStorage["home.indicators"]`에만 보존한다. 범례의 ×는 선택을 끈다.
- 차트 컨테이너 크기가 바뀌면 약 80ms 뒤 전체 구간을 다시 맞춘다.
- 1366px에서는 차트 아래에 수급·잔고와 파생을 두고, 오른쪽 계좌 아래에
  오늘 일정·브리핑을 둔다. 두 열은 각각 쌓여 차트 카드가 오른쪽 열의
  높이만큼 늘어나지 않는다. 375px에서는 지표 칸을 두 개씩, 차트를
  300px 높이로 표시하며 가로 스크롤을 만들지 않는다.
- 지표 보조문과 상태 칩은 겹치거나 화면 밖으로 밀리지 않아야 한다.
  상태 칩의 전체 문구는 `title`로 제공한다.

## 계좌와 관심종목

- 포함된 계좌 중 하나라도 현금이 미확인이면 현금 비중은 `—`이고
  `현금 미확인 계좌 포함` 설명을 제공한다. 0보다 크고 0.05% 미만인 비중은
  `0%`가 아니라 `<0.1%`로 표시한다.
- 선택 기간을 충족하는 계좌 관측 이력이 없으면 기본 기간은 `전체`다.
  기간별 증권사 손익이 없으면 계좌 요약의 증권사 표시 손익을 사용한다.
- 원화 금액은 규모에 따라 조/억/만 단위로 표시하며 1억 미만 달러 자산의
  원화 환산액도 만원 단위를 사용한다.
- 국내 주식 행은 `kr_equity_investor_flow_daily`의 최신 세션 외국인·기관·개인
  순매수를 억원 단위와 방향색으로 표시한다. 각 값의 툴팁에는 같은 종목의
  최근 5·20세션 합계와 기준일을 둔다. 데이터가 없는 국내 종목과 국내·미국
  ETF는 `—`를 표시하며 다른 종목 값으로 대체하지 않는다. 375px에서는 세
  열을 숨기고 종목명 아래에 `외 … · 기 …` 당일 요약만 둔다.
- 미국 종목은 긴 ETF 이름 대신 ticker를 표시하고 전체 이름은 `title`로
  제공한다. 한국 종목명은 그대로 표시한다. `row.held`는 `보유` 배지로,
  나머지는 `관심`으로 표시한다.
- 계좌 카드 아래에는 `summary_rows`의 계좌별 포함 상태와 기준 시각,
  `recent_cashflows`의 최근 입출금 최대 5건을 표시한다. 금액은 홈의 기존
  원화 축약 포맷을 사용하며 누락된 목록은 `—`로 남긴다.

## 수급·일정·브리핑

- `sections.flows.lending`은 신용잔고 바로 아래의 대차잔고 행이다. 현재
  잔고는 조/억 단위, 1일·5일 변화는 방향색, `trend_20d`는 20일
  미니그래프로 표시한다. 신용잔고와 대차잔고는 값 옆에 각각의 `MM-DD 기준`
  을 두고, 툴팁에 KOFIA D+2와 공공데이터포털 D+1 발표 시차를 설명한다.
  수급 기준일이 한국장 마감일과 다르면 순매수 표 제목에도 기준일을 표시한다.
- `sections.schedule.events`는 오늘 일정에 시각과 문장으로 표시한다.
  `briefs` 중 가장 늦은 시각의 브리핑 제목과 본문을 보여주며 본문은
  줄바꿈을 보존하고 기본 8줄 이후 접는다. 브리핑이 없으면
  `브리핑 없음 · 07:30/16:10 생성`을 표시한다.

## 페이로드

- `sections.flows.lending`는 `kr_stock_lending_market_daily`의 최신
  `balance_amount`와 1·5세션 변화율, 최근 20개 세션 원값, 기준일을
  제공한다. `lag_note`는 D+1 공개를 설명하고, 함께 제공되는 신용잔고
  메타데이터는 `kr_credit_balance_daily`의 최대 날짜와 KOFIA D+2
  `lag_note`를 제공한다. 데이터가 없거나 읽을 수 없으면 `null`이며 다른
  수급 행은 계속 제공한다.
- `sections.schedule`은 KST 오늘의 `morning`/`close` Markdown 중 front
  matter의 `sent`가 참인 브리핑만 최신 생성 시각 순으로 제공한다. 제목은
  본문의 첫 비어 있지 않은 줄이고, 나머지 본문은 출처·주의 문구를
  보존한 채 40줄로 제한한다. `🌙 오늘 밤` 또는 `📅` 블록의 시각 행만
  `events`로 승격하며 별도 출처가 없다는 사실은 `note`로 명시한다.
- 관심종목의 `held`는 계좌 페이지와 같은 로컬 계좌 로더가 확인한 종목
  식별자만 비교한다. KB 한국 종목의 공급자 접두사 `A`는 제거하고, 미국
  ETF 티커는 대문자로 정규화한다. 홈에는 수량이나 보유 비중을 추가하지
  않고 `held_count`와 불리언만 제공한다.
- 수급이 있는 국내 주식 행의 `investor`는 `as_of`와 외국인·기관·개인의
  `*_1d`, `*_5d`, `*_20d` 합계를 원 단위 정수로 제공한다. 데이터셋은
  `pyarrow.dataset.dataset(..., partitioning=None)`로 읽어 6자리 문자열
  종목코드를 보존하며, 종목별 날짜 중복을 제거한 최신 세션 순서로 합산한다.
  수급이 없는 행은 `investor` 키를 만들지 않는다.
- 국면 근거 행은 `label`, `value`, `evidence`, `hint`를 제공한다. 근거 없는
  자리표시자는 `evidence=false`다. 변동성 백분위는 `낮을수록 안정`, PER은
  `낮을수록 저평가`, 신용잔고는 `높을수록 과열`, 과매도 강도는
  `높을수록 과매도`로 해석한다. `research_current`는 그대로 유지한다.
- 한국 3Y·10Y 칸은 BOK 곡선이 더 최신이면 BOK를, 아니면 Toss
  `kr_treasury_yield_daily`를 사용하며 `source_label`에 공급자와 기준일을
  표시한다. 파생상품의 검증 전 영문 공급자 경고는 짧은 한국어 상태로
  바꾸고 미국 미지원 값은 `미표시`로 제한한다.
- 계좌 카드의 `summary_rows`와 최대 5개의 `recent_cashflows`는 계좌 페이지가
  이미 공개한 출처·입출금 필드만 축약한다. 새 계좌 금액이나 종목 수량,
  직접 계좌 식별자는 추가하지 않는다.
