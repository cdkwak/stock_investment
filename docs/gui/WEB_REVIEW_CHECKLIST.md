리뷰 세션은 **읽기 전용**이다. 코드·설정·데이터를 고치지 않고, 발견한 문제를 볼트
`20 Personal Knowledge/Investing/대시보드 요구사항.md` → `## 작업 큐` → `### 대기` 맨 위에
`- [ ] [리뷰 MM-DD HH:MM] <페이지> · <증상 한 줄> · <재현: URL/조작> · <심각도 상/중/하>` 형식으로 적는다.
같은 증상이 이미 큐에 있으면 다시 적지 않고 그 줄 끝에 `(재확인 MM-DD)`만 붙인다.

- 페이지: `/` 홈, `/market` 시장, `/stocks` 종목, `/account` 내 계좌, `/data` 데이터, `/research` 검증.

## 공통 (모든 페이지)
1. 콘솔 오류 0건인지 (`read_console_messages onlyErrors`). 네트워크 4xx/5xx 없는지.
2. 글자가 잘리거나 겹치는 칸, 가로 스크롤이 페이지 전체에 생기는지(카드 안 스크롤은 허용).
3. 날짜 표시가 실제 최신 데이터와 맞는지: 헤더 "데이터 갱신" 칩과 `/data` 페이지 정시·지연 수가 같은지.
4. "자료 없음 · 표시 불가 · 미표시 · 대기" 문구가 붙은 칸은 이유가 같이 보이는지(이유 없는 빈칸은 문제).
5. 숫자 이상: `NaN`, `undefined`, `0.0%`가 줄줄이, 어제 날짜인데 "오늘"이라고 쓴 곳, 통화 기호 누락.

## 홈 `/`
- 국면 밴드: 접힌 상태에 근거 한 줄 요약이 보이고, "근거 펼치기"로 상세 행 + 판정 규칙 한 칸만 열리는지. 미국장에 "기술 ·반도체" 부판정이 있는지.
- 타일 12개 + 더 보기 4개. 미니그래프 색이 등락 방향과 맞는지.
- 차트: 카드가 오른쪽 열 높이를 채우되 그래프는 540px 넘지 않는지. 지표 추가 메뉴(RSI14 등) 동작.
- 관심종목: 보유 배지, 조건 도달 문구, RSI 열, SKHY 행, "밤사이 미국" 줄(17:00~06:00 KST에만 값이 최신).
- 수급·잔고: 신용잔고·대차잔고 기준일 표시. 파생 카드에 VIX 기간구조·SKEW.
- "오늘 달라진 것" 스트립: 칩 6종, 클릭하면 목록. 전부 0이면 의심(장이 열린 날은 신고가·거래량 급증이 0일 수 없음).
- 오늘 판단 한 줄: 저장 → 볼트 오늘 일지에 붙는지(내용은 확인용 한 줄만, 금액 문장은 거부돼야 정상).
