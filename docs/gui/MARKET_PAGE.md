# 시장 페이지 표시 계약

Status: `IMPLEMENTED_PROVIDER_FREE / DESCRIPTIVE_ONLY / NOT_A_SIGNAL`

## 경계

시장 페이지는 보존된 로컬 데이터를 읽기 전용으로 설명한다. 수급, 파생,
잔고, 시장 폭, 밸류에이션은 설명용 관측이며 추천·적합성 판단·기대수익·주문 신호가 아니다.
입력의 단위, 기준일, 최종성 또는 의미가 확인되지 않으면 숫자를 추정하거나
다른 공급자 값으로 대체하지 않고 `표시 불가`로 남긴다.

## 차트와 조회 범위

- Lightweight Charts는 주가 캔들 차트 한 곳에서만 사용한다.
- Basis, PCR 2종, KOSPI/KOSDAQ 투자자 순매수, 신용·대차잔고,
  KOSPI/KOSDAQ PER·PBR은 공용 인라인 SVG 차트를 사용하며 hover tooltip을
  유지한다. PER과 PBR은 값의 규모가 달라 각각 위·아래 패널과 독립 축으로
  표시하고 두 축의 표시 하한은 0이다.
- 작은 시계열 카드는 첫 응답에서 화면 기본값만 받는다. Basis/PCR,
  신용·대차잔고, KOSPI/KOSDAQ PER·PBR 이력은 서버에서 `1Y`로 자르고,
  `3Y / 5Y / 전체`를 실제로 선택할 때만 클라이언트가 더 긴 범위를 지연
  조회한다. 시장 폭은 최신 시장별 스냅샷만 포함한다.
- 투자자 순매수만 `20일 / 60일 / 1년 / 전체`를 사용하고 기본값은 `60일`이다.
  `/api/market`의 기본 문서는 일별·누적 배열 모두 시장별 최근 60거래일만
  포함한다. 범위 변경은 기존 라우터 파라미터인
  `GET /api/market?flows_range=20D|60D|1Y|3Y|5Y|ALL`을 다시 조회하며 서버는
  요청 범위별 결과를 캐시한다. `3Y / 5Y` 요청에서 투자자 순매수 자체는 기본
  60거래일을 유지하고, 나머지 작은 이력만 해당 범위로 확장한다.
- 외국인·기관·개인의 일별 순매수는 정수 억원이며, 기본 선은 선택 범위 첫날의
  순매수부터 포함한 누적 합계다. 범례는 각 선을 끄고 켤 수 있고 `일별`은 현재
  범위의 막대 보기다. 범례 영역에는 단위 `억원`을 한 번 명시하고 축은 절댓값
  10,000억원부터 조 단위로 바꾼다.

## 주가 지표

MA5/20/60/120, 거래량, RSI14는 받은 캔들로 브라우저에서 계산한다. 지표를
켜거나 배치를 바꿀 때 API를 다시 호출하지 않으며 종목·봉·기간이 바뀔 때만
조회한다. 각 지표는 `겹쳐 보기`와 `아래 창`을 선택할 수 있다. 이동평균은
기본 overlay, 거래량과 RSI14는 기본 별도 패널이며 RSI에는 30/70 안내선을
표시한다. 선택과 배치는 localStorage에만 보관하고 시장 값은 저장하지 않는다.

## 단위와 기준일

금액 축·tooltip·대표값은 `조 / 억 / 만` 단위로 축약한다. 비율은 소수점 한
자리, PCR은 두 자리, 투자자 순매수는 정수 억원으로 표시한다. 각 카드에는
기준일을 노출하고, 과거 일자의 선물·옵션 관측은 `D+1 공개`임을 함께 표시한다.
밸류에이션의 동일 통계 문구는 정수 반올림한
`5년 백분위 67% (상위 33%)` 형식으로 통일한다. 밸류에이션 패널의 설명
아이콘은 패널당 하나이며 PER, PBR, 5년 백분위/상위 비율 정의를 한 tooltip에
합친다.

시장 폭의 `상승 / 하락 / 보합 / A/D`와 대차잔고의 `값 / 1일 / 5일`은 서로
다른 payload 키와 표를 사용한다. 두 표의 A/D 및 대차잔고 제목에는 정의와
중립적 해석을 담은 설명 tooltip을 제공한다.

## Call / Put Wall

기존 `call_wall_*`와 `put_wall_*`는 전체 행사가 최대 OI 기록으로 유지한다.
화면은 같은 날의 명시적 KOSPI200 기초자산을 결합한 뒤 ±15% 안에서 최대
양의 OI를 고르는 `near_call_wall_*`와 `near_put_wall_*`만 사용한다. 동률은
가장 낮은 행사가를 대표값으로 삼고 후보 수와 후보 행사가를 보존한다. 창 안에
양의 OI가 없으면 Wall 숫자를 숨기고 그 상태를 설명한다. 구 형식 CSV는 읽을
수 있지만 근접 Wall로 가장하지 않는다.

## 설명

지표 머리말의 `ⓘ` 문구는 `stock_web.api.market_page.METRIC_EXPLANATIONS`가
단일 소유자다. 문구는 정의와 중립적인 읽는 법만 제공하며 추천 표현을 쓰지
않는다.

LS 원시 관측 경고는 웹 projection 경계에서 한국어로 바꾼다. 알려진
`Raw provider observation; no Normalized/PIT-safe claim`은
`원시 관측값 · 정규화 전 · 수동 검증 전에는 표시하지 않습니다`로 표시하고,
그 밖의 ASCII 전용 경고도 영어를 그대로 노출하지 않고 일반 한국어 안내로
대체한다.

현재 시장 모듈에는 startup/refresh warm hook이 없다. `__main__.py`의 기존 홈
warmup과 시장 기본 범위 cache warmup을 함께 등록하는 후속 변경을 권장한다.

2026-09-05부터 시장 payload와 데이터 페이지 context는 보존 입력의
`(path, mtime_ns, size)` 서명으로 프로세스 내 cache를 무효화하며, 기본 파생
이력은 전체 연도 파일 대신 표시 범위를 충족하는 최신 행만 읽는다. 같은
프로세스의 최종 TestClient 3회 측정은 `/api/market` 52.1/49.0/46.9ms,
`/data` 7.8/7.9/8.2ms였고 Market JSON은 변경 전 payload와 일치했다.
