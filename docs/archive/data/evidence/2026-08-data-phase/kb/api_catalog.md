# KB증권 Open API 카탈로그

공식 샘플 ZIP의 JSON 파일명(stem)을 API 코드로 사용해 분류했다. 용도는 Excel 시트명과 코드가 일치하는 경우에만 기록했으며, 공식 명칭을 확인할 수 없는 항목은 `확인 필요`로 남겼다. 이 자료는 개발 참고용이며 런타임 입력으로 사용하지 않는다.

## 인증 (2)

| API 코드 | 용도 |
|---|---|
| `token` | Access Token 발급 |
| `revoke` | Access Token 폐기 |
