# KB증권 검증·사용 현황

이 문서는 실제로 호출 또는 연동 검증을 마친 항목만 기록한다. 공식 Excel과 JSON 샘플은 개발 참고자료이며 런타임 코드에서 읽지 않는다.

## 공통 확인 사항

- 요청 본문은 `dataHeader`와 `dataBody`의 중첩 구조를 사용한다.
- HTTP 상태, `dataHeader.resultCode`, 객체형 `dataBody`, API별 필수 응답 구조를 함께 검증한다.
- `processCode`는 API별 진단값이며 모든 API에 공통인 성공값으로 고정하지 않는다.
- 인증정보, 계좌번호, 실제 잔고, Access Token, 요청·응답 전문은 기록하지 않는다.

## 검증된 엔드포인트

| 항목 | 확인 결과 |
|---|---|
| `token` | Access Token 발급 성공. 정상 응답의 `processCode`는 `0000`. 토큰은 프로세스 메모리에만 보관하고 만료 60초 전부터 재발급한다. |
| `IVSA0070` | 시장종합 조회 성공. 정상 응답의 `processCode`는 `0024`. KOSPI·KOSDAQ 시장 폭과 선택 배열 구조를 확인했다. |
| `SSQM2952` | 잔고현황조회(체결기준) 연결 성공. 정상 응답의 `processCode`는 `0011`. 실제 잔고·종목·수량은 문서화하지 않는다. |

## 검증된 연동

| 항목 | 확인 결과 |
|---|---|
| 시장 폭 일별 수집 | `IVSA0070` 응답의 조회일자를 시장 날짜로 사용해 KOSPI·KOSDAQ 시장 폭만 원자적으로 누적한다. 같은 날짜는 최신 응답으로 교체한다. |
| 업데이트 파이프라인 | 기존 국내·미국·FRED 단계와 검증 이후 KB 시장 폭을 선택적 외부 API 단계로 실행한다. KB 단계 실패는 기존 결과와 유효 CSV를 손상시키지 않고 별도 상태로 반환한다. |
