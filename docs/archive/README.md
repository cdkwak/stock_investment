# Documentation Archive

Everything below this directory is historical evidence, not current routing or
execution authority. Start from [`docs/README.md`](../README.md), then follow the
current Project and domain Status.

## Layout

| Path | Contents |
|---|---|
| `project/` | Superseded project controls and dated repository audits |
| `data/evidence/` | Closed source samples, inventories, and validation evidence |
| `data/operations/.../completed/` | Completed, one-shot, and terminal operations |
| `data/operations/.../superseded/` | Procedures replaced by current routes |
| `<domain>/status_history/` | Exact pre-compaction Status snapshots |

Archived relative links may reflect their original location and are not a
navigation guarantee. Use a current registry or Status when locating active
code and procedures. Do not move an archived document back into an active tree
merely because it contains a once-valid instruction.
